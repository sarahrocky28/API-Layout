# Nome do Projeto
PRODUTOS JS

## Descrição
O projeto é um site que faz busca de produtos por uma API. Ele retorna nome do produto, preço em reais, avaliação e quantidade que tem no estoque.

## Tecnologias Utilizadas
As tecnologias utilizadas foram html, css e javascript.

## Como Executar  
Para executar basta você ter acesso ao link, sem a necessidade de baixar alguma coisa extra. O link é https://sarahrocky28.github.io/API-Layout/
